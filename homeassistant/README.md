# Percia Bridge (Home Assistant add-on)

Add this repository to Home Assistant: **Settings → Add-ons → Add-on store → ⋮ → Repositories** and paste `https://github.com/velvee-ai/percia-bridge`. Then install **Percia Bridge**. See [DOCS.md](DOCS.md) for setup.

The add-on is a thin wrapper around the multi-arch image `ghcr.io/velvee-ai/percia-bridge` (amd64, aarch64).
